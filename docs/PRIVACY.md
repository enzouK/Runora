# Política de Privacidade — Runora

**Última atualização:** outubro de 2026

## 1. Quais dados coletamos
O Runora é um app de flashcards que roda localmente (navegador / Windows / Android). Os seus decks, cards, imagens e configurações ficam armazenados **no próprio dispositivo** (localStorage / IndexedDB / arquivos locais).

## 2. Google Drive (sincronização opcional)
Se você optar por conectar sua conta Google para sincronizar, o app cria apenas os arquivos da própria sincronização na **sua** conta do Google Drive (`runora-sync.colpkg`, `runora-sync-meta.json`, `runora-sync.lock.json`), com o escopo `drive.file` — que dá acesso somente a arquivos criados pelo próprio app. O token de acesso fica apenas no seu dispositivo e nunca é enviado a servidores nossos (não há servidor nosso: o app fala direto com a API do Google).

## 3. Compartilhamento
Não vendemos, alugamos ou compartilhamos seus dados com terceiros. Não usamos analytics, anúncios ou trackers.

## 4. Seus direitos
Você pode desconectar o Google Drive a qualquer momento nas Configurações do app e apagar os arquivos de sync direto no seu Drive. Para excluir todos os dados locais, limpe os dados do site/app no dispositivo.

## 5. Contato
Dúvidas sobre esta política: abra uma issue em https://github.com/enzouK/Runora ou pelo e-mail de suporte cadastrado no Google Cloud.
